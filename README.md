# Naru Webinar - 연봉 성장 전략

마크다운 기반 프레젠테이션 프로젝트. 동일한 내용을 Marp, Slidev, reveal.js 세 가지 도구로 제작.

## 실행 방법

### Marp (마크다운 → PPT/PDF/HTML)

```bash
npm run preview          # 브라우저 실시간 미리보기
npm run html             # HTML로 내보내기 (slides.html)
npm run pdf              # PDF로 내보내기 (slides.pdf)
npm run pptx             # PPTX로 내보내기 (slides.pptx)
```

### Slidev (Vue 기반, 애니메이션)

```bash
npm run slidev           # 개발 서버 실행 (localhost:3030)
npm run slidev:build     # 정적 사이트 빌드
npm run slidev:export    # PDF 내보내기
```

### reveal.js (3D 전환, 세로 슬라이드)

```bash
npm run reveal           # 로컬 서버 실행 (localhost:3030/reveal.html)
```

## 설치

```bash
npm install
```
